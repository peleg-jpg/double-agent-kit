# חיבור הכלים ל-Claude (פעם אחת לכל כלי)

בשיעור 7 רואים את כל זה קליק אחרי קליק. החיבור של ElevenLabs חוזר בשיעור 13, ושל HeyGen בשיעור 15.

לא צריך מפתח API לאף אחד משלושת הכלים. מתחברים עם החשבון שלכם בדפדפן, וזהו.

**איפה:** באפליקציה של Claude, נכנסים ל-Settings ואז ל-Connectors.

## ElevenLabs (הקול)

1. לוחצים על + ובוחרים Discover (או עוברים ללשונית Discover). זאת החנות של כל הכלים.
2. כותבים בחיפוש ElevenLabs.
3. לוחצים Connect (או על הפלוס שליד השם).
4. נפתח הדפדפן ושואל אם מותר ל-Claude להיכנס לחשבון שלכם. לוחצים Authorize.
5. חוזרים ל-Claude, ולמטה כתוב Connected. זאת אומרת, מחובר.

## Apify (הנתונים)

בדיוק אותו דבר: + ואז Discover, מחפשים Apify, לוחצים Connect ומאשרים Authorize בדפדפן.

לא מופיע לכם? מוסיפים אותו ידנית, כמו את HeyGen:

- Name: <span dir="ltr">Apify</span>
- URL: <span dir="ltr">`https://mcp.apify.com`</span>

## HeyGen (האווטאר)

את HeyGen מוסיפים ידנית:

1. לוחצים Add, ואז Add custom connector. נפתח חלון קטן עם שני שדות.
2. בשדה Name כותבים: HeyGen
3. בשדה URL מדביקים, בדיוק אות באות: <span dir="ltr">`https://mcp.heygen.com/mcp/v1/`</span>
4. לוחצים Add. נפתח הדפדפן, לוחצים Authorize, וחוזרים ל-Claude.

שימו לב: ב-Discover תמצאו רק "HyperFrames by HeyGen". זה כלי אחר (אנימציה וגרפיקה), לא האווטאר. לכן מוסיפים ידנית.

## בודקים שהכל מחובר

1. פותחים שיחה חדשה בקלוד קוד (חיבור חדש נטען רק בשיחה חדשה).
2. כותבים <span dir="ltr">`/mcp`</span> ושולחים.
3. ברשימה צריך לראות ElevenLabs, HeyGen ו-Apify, ולידם וי.

אחד חסר, או שכתוב לידו Connect? לוחצים Manage Connectors, מחברים אותו שוב, ופותחים שיחה חדשה.

אפשר גם להדביק לקלוד את הפרומפט <span dir="ltr">`prompts/0_check_connections.txt`</span>, והוא יגיד לכם מה מחובר ומה לא.
